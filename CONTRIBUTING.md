# Contributing

Thanks for helping improve Persian RTL Markdown Preview.

## Report a bug

Open an issue and include:

- A minimal Markdown sample that reproduces the problem.
- The expected and actual direction or layout.
- Your VS Code version, operating system and theme.
- A screenshot when the problem is visual.

Please remove private or sensitive information from samples and screenshots.

## Submit a change

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Add or update tests for behavior changes.
4. Run `npm test` and `npm run package`.
5. Open a pull request describing the problem and the chosen solution.

Keep the extension dependency-free at runtime and avoid modifying VS Code core files.
