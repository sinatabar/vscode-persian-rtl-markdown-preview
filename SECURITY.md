# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option in the repository Security tab to send a private report.

Include a description, reproduction steps, affected versions and the potential impact. You can expect an initial response within seven days.

The extension does not collect telemetry, make network requests or execute Markdown content outside VS Code's standard preview environment.
